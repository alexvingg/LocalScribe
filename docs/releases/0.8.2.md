LocalScribe 0.8.2 makes the configured translation destination explicit and keeps implementation code and localization keys in English.

## Changes

- Translation prompts include the selected target language name and code, independently of the interface language and detected source language.
- Current-passage translation, suggestion cards, and demonstration previews follow **Translate to**. Existing saved preferences are preserved.
- English source keys for all 173 interface messages, with English and Portuguese localization catalogs. Swift comments, diagnostics, and prompts use English.
- Multilingual review vocabulary and synthetic regression samples are bundled JSON resources. Portuguese and Unicode test coverage is preserved.
- Includes automatic language detection, word corrections, sentence rewrites, on-demand translation, app exclusions, and the existing weekday-fidelity safeguard.

## Downloads and installation

Choose **LocalScribe-0.8.2-arm64.dmg.zip** to preserve the DMG file icon metadata in Finder, or download the direct DMG. Extract the ZIP, open the DMG, and drag LocalScribe to Applications. Both contain the green mounted-volume and app icons. English installation instructions are included as `INSTALL.txt`.

Download `SHA256SUMS` alongside the installers and run `shasum -a 256 -c SHA256SUMS` to verify them.

Requirements: Apple Silicon, macOS 26.4 or later, Apple Intelligence enabled with the on-device model ready, and Accessibility permission for LocalScribe. After replacing an ad hoc signed build, macOS may require renewing Accessibility authorization and reopening the app.

## Validation and limitations

- 64 core checks passed, with zero failures; 173 localization keys and 63 multilingual sample references checked.
- All 15 selectable translation targets passed the deterministic configuration/persistence/cache check. This is not a real-model quality test of all 15 languages.
- Real on-device translation passed English → Portuguese, Portuguese → English, and English → Spanish, including Friday → sexta-feira, protected numbers/addresses, line breaks, and request lifecycle checks.
- The real model corrected `She go to school every days.` to `She goes to school every day.`; local spelling checks passed. The installed app had Accessibility authorization and could read the active Chrome field. Applying corrections in host editors was not retested for this release.
- English, Portuguese, and unsupported-interface-language fallback checks passed. DMG integrity, code signature, and installer icons were verified.
- Ad hoc signed test build, without Developer ID signing or Apple notarization. Editor support depends on the field; suggestions and translations may be inaccurate. No LocalScribe account, subscription, API key, custom backend, or extra translation language packs.
