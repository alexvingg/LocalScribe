LocalScribe 0.8.3 fixes Japanese translation that previously stayed loading and then failed validation.

## Changes

- Plain-text translation replaces a structured JSON string field that caused the installed model to append Japanese explanations and repetitions. The prompt still follows the user-selected target language and treats supplied text as data.
- Response budgets scale with passage length, from 128 to 900 tokens. Responses close to the generation limit are rejected rather than displayed as potentially incomplete translations.
- Known original email addresses and URLs are separated from adjacent CJK prose before exact validation. Modified addresses, links, numbers, and duplicate entities remain rejected.
- Japanese regression checks cover the screenshot greeting, a short sentence, and a passage with a number, email, URL, and Friday. Repeated card requests reuse the memory cache.

## Validation

66 core checks passed. The real on-device model passed English → Japanese, English → Portuguese, Portuguese → English, and English → Spanish smoke checks. The Japanese cases completed in approximately 0.8–2.3 seconds in the measured debug run, compared with approximately 21 seconds followed by rejection before the fix. This is an observation on the test Mac, not a performance guarantee.

The 173 English/Portuguese localization keys remain valid. Runtime diagnostics do not log user text; the explicit smoke checks print only their synthetic examples. Applying corrections in external editors was not retested for this translation change.

## Installation and limits

Choose the DMG or its ZIP wrapper, which preserves Finder icon metadata. Drag LocalScribe to Applications. Check downloads using the accompanying `SHA256SUMS` file.

Requires Apple Silicon, macOS 26.4 or later, the Apple Intelligence on-device model ready, and Accessibility permission. The build is ad hoc signed and is not Apple notarized; replacing the app may require renewing Accessibility authorization and reopening it. Suggestions and translations can contain mistakes. No LocalScribe login, subscription, API key, custom backend, or additional translation language packs.
